# My Portfolio

A personal portfolio built with **Next.js** to showcase my skills, experience, education, and projects as a Full-Stack Developer.

🌐 **Live Demo:** https://my-portfolio-smoky-xi-63.vercel.app/

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## ✨ Features

- Responsive design
- About me and professional experience
- Skills and education
- Featured projects
- Contact information

## 🚀 Getting Started

```bash
git clone https://github.com/jahir002201/my_portfolio.git
cd my_portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
